## О программе</div>

<p align="justify">
Программа <b><i><code>"Прикладной анализ данных"</code></i></b> фокусируется на практическом применении <a href="https://en.wikipedia.org/wiki/Machine_learning"><b><i><code>методов машинного обучения</code></i></b></a> и <a href="https://en.wikipedia.org/wiki/Data_analysis"><b><i><code>анализа данных</code></i></b></a>. Студенты освоят <a href="https://www.python.org/"><b><i><code>Python</code></i></b></a>, углубятся в <a href="https://en.wikipedia.org/wiki/Category:Machine_learning_algorithms"><b><i><code>алгоритмы машинного обучения</code></i></b></a>, включая <a href="https://en.wikipedia.org/wiki/Deep_learning"><b><i><code>глубокое обучение</code></i></b></a>, и научатся решать практические задачи с использованием современных инструментов и библиотек. Курс сочетает теорию с практикой: от имплементации алгоритмов до участия в соревнованиях на платформах, таких как <a href="https://www.kaggle.com/"><b><i><code>Kaggle</code></i></b></a>.
</p>

<p align="justify">
В рамках курса студенты получат навыки <b><i><code>анализа и обработки данных</code></i></b>, <b><i><code>разработки</code></i></b>, <b><i><code>обучения и оценки базовых моделей машинного обучения</code></i></b>, <b><i><code>разработки нейронных сетей</code></i></b>.
